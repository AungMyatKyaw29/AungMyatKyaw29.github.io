# Aung Myat Kyaw — Portfolio

A responsive, dependency-free portfolio for GitHub Pages. Open index.html in your browser to preview. No installation or build step is required.

## Personalise before publishing

1. At the bottom of index.html, fill in PROFILE.email, PROFILE.github, PROFILE.linkedin, and optionally PROFILE.cv with your real details. Use full https:// URLs for profiles. For a CV, add a PDF to the same folder and use './cv.pdf'. Empty fields stay hidden.
2. Check your biography, education and project descriptions for accuracy.
3. Replace the illustrative project visuals with real screenshots when available. No reported performance numbers are included until you verify them against your final results.
4. Add your project repository links inside the relevant project details once available.

## Publish using GitHub Pages

Create a repository named YOUR_USERNAME.github.io (replace YOUR_USERNAME with your GitHub username). Upload index.html to the repository root. In the repository's Settings → Pages, choose publishing from the main branch and root folder. Follow GitHub's displayed deployment status and website link. You can also use another repository name for a project site.

This website is static. It describes your AI projects; it does not run the Python models. There is no contact form or backend. Email uses a mailto link once configured.

## Files

- index.html — complete website, styles, and small JavaScript enhancements
- README.md — setup and editing instructions
- .nojekyll — allows plain static publishing

Accessibility features include a skip link, visible keyboard focus, native expandable project details, and reduced-motion support. All assets are local or embedded; no third-party scripts, fonts, or tracking.
