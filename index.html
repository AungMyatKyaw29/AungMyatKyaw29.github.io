Final-year project

Student Helpdesk Chatbot

A Flask chatbot combining a trained PyTorch LSTM intent classifier, controlled helpdesk answers, and a local Qwen3 1.7B model through Ollama.

Python PyTorch LSTM Flask Ollama qwen3:1.7b
Read project details

Data preparation: Combined raw student-query examples with additional examples generated using Qwen3 1.7B through Ollama, then prepared labelled CSV data for training.

Model training: Cleaned and tokenised the queries, built a vocabulary and label encoder, and trained a lightweight LSTM to recognise common helpdesk intents.

Response workflow: The Flask interface passes questions to the intent classifier. Helpdesk queries use a local answer bank. Suitable general or maths queries can use the local Ollama model as a fallback.

Evaluation: The poster presents accuracy and loss curves, a confusion matrix, and ROC analysis.
